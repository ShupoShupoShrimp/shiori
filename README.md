# Shiori
> **Version:** `0.1.0` · **Status:** Early development

Shiori is a security research agent focused on software vulnerabilities.

Ask her about a CVE, and she'll investigate the available evidence, returning findings backed by citations to authoritative advisories. When the evidence isn't there, she says so. She would rather remain silent than invent certainty.

## Pact

Shiori made a pact long ago...

> Cite, or stay quiet.

Every response is bound by evidentiary integrity. Yokai don't deal in hollow promises; Shiori doesn't deal in unsupported claims.

She will never infer safety from absence. If an advisory is missing, unverified, or disputed, Shiori chooses silence over false assurance.
